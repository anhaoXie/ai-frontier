# 配套技能：ai-frontier-daily

这个目录是 **DSH 技能文件的一份参考副本**，不是能直接运行的程序。

## 它是什么

`SKILL.md` 是给 AI（DSH 会话里的助手）看的**操作说明书**，规定了：

- 怎么读候选清单（`out/candidates/latest.json` 的结构）
- 怎么用领域判断从 120 条候选里挑出 8-15 条真正重要的
- **必须联网核实头部条目**，以及核实到什么程度才算够
- 报告要写成什么结构（今日要点 / 事实 / 为什么重要 / 不确定的地方）
- 硬规则：不许编、区分事实与推测、必须写来源体检

## 它和你双击的那个程序的区别

| | 图形界面（`启动AI前沿雷达.cmd`） | 这个技能 |
|---|---|---|
| 采集 | ✅ 按钮 | 可以代跑 |
| 看清单 / Excel | ✅ 按钮 | 可以代开 |
| 生成报告 | ✅ 但**只是本地筛选整理** | ✅ 联网搜证 + 领域判断 |
| 联网核实 | ❌ | ✅ |
| 判断重要性 | ❌ | ✅ |

图形界面上的「生成报告」按钮产出的是**数据摘要**（`src/local_report.py`），
按你选的条件切片，逐条列出标题摘要热度链接。它不联网、不判断。

**带判断的报告只有 AI 能写**，因为需要读懂内容后再去搜索验证。
这就是这个技能存在的理由。

## 怎么用它（在 DSH 里）

技能必须放在 DSH 会扫描的技能目录才会被识别：

```
<工作区>/.dsh/skills/ai-frontier-daily/SKILL.md      # 项目级（rank 100）
~/.dsh/skills/ai-frontier-daily/SKILL.md             # 用户级（rank 400）
```

安装：把本目录整个复制到上面任一位置。

然后在这个项目的会话里说：

> 跑一下今天的 AI 前沿日报

## 注意：路径是相对于项目根的

`SKILL.md` 里写的路径（如 `ai-frontier/out/candidates/latest.json`）是
**按"技能装在 DSH 工作区、项目在工作区下的 ai-frontier/ 子目录"** 这个
布局写的。如果你把项目 clone 到别的位置，需要相应调整技能里的路径。

如果你只想跑采集和本地摘要，不需要这个技能 —— 双击界面就够了。
